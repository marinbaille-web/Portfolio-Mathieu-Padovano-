# Importer le portfolio sur GitHub

Le dossier est prêt pour un déploiement GitHub Pages depuis la branche `main` et le dossier `/ (root)`.

## Important
- Importer **le contenu du dossier**, pas le dossier parent lui-même.
- Conserver exactement les noms de fichiers et de dossiers.
- Ne pas déplacer `index.html` : il doit rester à la racine.
- Le fichier `.nojekyll` est volontairement vide.

## Structure principale
- `index.html`
- `a-propos.html`
- `bilan.html`
- `annexes.html`
- `competences/`
- `assets/`

Le guide détaillé de clics sera donné dans la conversation.
